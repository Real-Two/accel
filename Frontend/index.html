What changes?

Line 1: accel = accelerate(...)
Queries host CPU topology, checks SIMD vector flags, clamps PyTorch to measured P-core thread pool, and benchmarks precision safety.
Line 2: model = accel.model
Permutes model weights into channels-last memory layout (NHWC), matching Intel oneDNN vector alignment.
Line 3: accel.prepare_inputs(...)
Ensures incoming mini-batches match memory stride and caching format with zero in-loop allocation overhead.

How It Works: In Plain Language for Judges

How does CPUAccel speed up PyTorch by 2.95× without modifying the neural network?

1
Eliminates Disk Choke
Standard PyTorch re-reads and decompresses satellite HDF5 tiles on every epoch. CPUAccel caches normalized arrays directly in CPU RAM once.
2
SIMD Memory Alignment
Converts image tensors to channels-last layout (NHWC), aligning memory strides with CPU vector registers for maximum instruction throughput.
3
Zero Core Contention
Prevents OpenMP from spanning across slow E-cores. Clamps workers to 4 dedicated threads, eliminating L3 cache thrashing.
4
Intelligent Guardrails
Micro-benchmarks precision before applying flags: blocks 117× slowdown from software bfloat16 emulation and skips compile hangs.
